# 속담·사자성어 50문항 데이터 전달 사항

## 파일

- `data/proverbs.50.json`: 속담 50문항
- `data/idioms.50.json`: 사자성어 50문항

두 파일은 현재 Claude 구현안의 `RawProverb`와 `RawIdiom` 필드를 그대로
포함한다. `difficulty`와 `explanation`은 추가 메타데이터이므로 TypeScript에서
필요하지 않으면 무시해도 되고, 문제 선택 및 정답 공개 화면에 활용해도 된다.

## 구현 시 반드시 변경할 부분

현재 Claude 작업안은 문항 수를 30으로 고정하고 있으므로 다음을 50에 맞춘다.

1. `QUESTIONS_PER_TEXT_GAME`을 50으로 변경한다.
2. 서버가 읽는 파일을 이 두 파일로 지정하거나, 검증 후 기존
   `data/proverbs.json`과 `data/idioms.json`을 이 파일 내용으로 교체한다.
3. 클라이언트의 진행 표시를 `현재 문제 / 50`으로 변경한다.
4. 테스트의 30문항 기대값과 완료 조건을 50문항으로 변경한다.
5. 방마다 50문항을 한 번씩 무작위 순서로 내고 중복 출제하지 않는다.

## 문제 공개 및 정답 판정

- 속담 문제 중에는 `prefix`만 공개한다. 정답으로 `suffix`, `full`, `aliases`를
  인정한다.
- 사자성어 문제 중에는 `meaning`만 공개한다. 정답으로 `answer`, `hanja`,
  `aliases`를 인정한다.
- `full`, `suffix`, `answer`, `hanja`, `aliases`, `explanation`은 정답 공개 전
  클라이언트 페이로드에 포함하지 않는다.
- 기존 정답 정규화기를 사용하고 유사 문자열 퍼지 매칭은 추가하지 않는다.

## 난이도

각 파일은 `easy` 20개, `medium` 20개, `hard` 10개로 구성했다. 전체 문항을
모두 사용할 때는 난이도와 무관하게 전체를 섞는다. 일부 문항만 선택하는 기능을
추가할 경우에는 난이도별 비율을 유지한다.

## 검수 기준

- 파일별 문항 수 50개
- ID와 대표 정답 중복 없음
- 속담의 `prefix`와 `suffix`를 붙이면 `full`이 됨
- 사자성어 한글 정답과 한자 표기는 각각 네 글자
- 문제로 공개되는 단서에 정답 문자열이 포함되지 않음
