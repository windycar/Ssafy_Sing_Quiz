# 사용자 가이드 — Drop the Beat

온라인 노래 맞히기 게임 **Drop the Beat**의 화면과 조작 방법을 설명합니다.

> 이 문서는 `agent/claude` 브랜치의 **웹 클라이언트(`client/`)와 게임 서버**를
> 다룹니다. 여러 명이 같은 방에서 함께 플레이하며, 정답 판정은 전부 서버가
> 합니다. 별개로 배포되어 있는 `agent/codex` UI 프로토타입은
> [§7](#7-별개로-배포된-ui-프로토타입)을 참고하세요.

## 1. 접속 요건

| 항목 | 내용 |
| --- | --- |
| 방장 기기 | 스피커가 연결된 앞 컴퓨터. 노래는 여기서만 나옵니다 |
| 참가자 기기 | 폰으로 충분합니다. 소리도 영상도 나오지 않고 정답 입력만 합니다 |
| 브라우저 | 최신 Chrome, Edge, Safari, Firefox |
| 접속 주소 | 방장이 서버를 띄운 주소. 터널을 쓰면 실행할 때마다 새로 생깁니다 |
| 인원 | 방장 1명 포함 최대 20명 |

서버 실행 방법은 [`../README.md`](../README.md)의 "실행" 절에 있습니다.

### 왜 방장 컴퓨터에서만 소리가 나는가

유튜브로 진행할 때, 영상 ID를 참가자에게 보내면 **정답을 보내는 것과 같습니다.**
유튜브 플레이어는 영상 제목을 그대로 보여주고, 화면에서 가려도 개발자도구나
네트워크 요청으로 ID를 꺼내 유튜브에 붙여넣으면 제목이 나옵니다. 한 명만 그렇게
해도 게임이 끝납니다.

그래서 영상 ID는 방장에게만 가고, 참가자에게 가는 모든 경로에서 지워집니다.
**이 방식은 스피커가 있는 한 공간에 다 같이 모여 있을 때만 성립합니다.**
흩어져 있다면 유튜브가 아니라 음원 파일 모드를 써야 합니다
([§2-2](#2-2-곡-준비)).

## 1-1. 빠른 실행

`scripts/start-event.cmd`를 더블클릭하면 공개 주소가 하나 뜹니다. 참가자에게는
**그 주소와 참여 코드**만 알려 주면 됩니다.

> 주소는 실행할 때마다 달라지고, 창을 닫으면 사라집니다. 행사가 끝날 때까지
> 켜 두세요. 이미 끝난 주소로 접속하면 Cloudflare가 **오류 1033**을 띄웁니다.

## 2. 방장(호스트) 진행 순서

### 2-1. 방 만들기

1. 첫 화면에서 **방 만들기**를 누릅니다.
2. **출제 곡 수**를 정합니다(1~50).
3. 음원 파일 모드라면 **음원 등록**을 펼쳐 곡별 음원을 채웁니다
   ([§2-2](#2-2-곡-준비)). 유튜브 모드라면 서버를 켤 때 이미 끝나 있습니다.
4. 아래 **방 만들기**를 누르면 **참여 코드**와 참여 링크가 나옵니다.

참여 코드와 참여 링크는 참가자에게 알려 주는 값입니다. 그 아래 **방장 링크
복사**로 얻는 링크에는 방장 권한 토큰이 들어 있습니다.

> **방장 링크는 절대 공유하지 마세요.** 이 링크를 가진 사람은 누구나 게임을
> 시작하고 일시정지하고 스킵할 수 있습니다. 같은 탭에서는 새로고침해도 방장
> 권한이 유지되므로, 다른 기기에서 진행할 때만 이 링크가 필요합니다.

곡은 **무작위로 뽑히고 무작위 순서로** 출제됩니다. 곡 목록 자체는 음원 등록을
위해 공개되지만, 어떤 곡이 언제 나올지는 서버만 알고 있습니다.

### 2-2. 곡 준비

두 가지 방식이 있고, 섞어 쓸 수는 없습니다.

| 방식 | 언제 쓰나 | 소리가 나는 곳 |
| --- | --- | --- |
| **유튜브** (권장) | 한 공간에 모여 스피커로 듣는 경우 | 방장 컴퓨터만 |
| **음원 파일** | 참가자가 흩어져 있는 경우 | 참가자 각자 기기 |

#### 유튜브 — 플레이리스트 파일

곡 목록을 텍스트 파일에 미리 적어 두고 서버를 켤 때 넘깁니다. 20곡을 화면에서
하나씩 붙여넣는 것보다 빠르고, 파일이 남으니 다음에 또 쓸 수 있습니다.

```
# 한 줄에 한 곡. #으로 시작하는 줄과 빈 줄은 무시됩니다.

# 링크만 — 영상 제목을 읽어 곡을 자동으로 찾습니다
https://www.youtube.com/watch?v=9bZkp7q19f0

# 링크 | 정답 — 직접 지정합니다. 곡 목록에 없는 노래도 됩니다
https://youtu.be/kJQP7kiw5Fk?t=60 | Despacito, 데스파시토
```

- **시작 지점**: 유튜브에서 *현재 시간부터 공유*를 체크하고 복사하면 링크에
  `?t=75`가 붙습니다. 그 지점부터 재생됩니다. 후렴 시작점을 넣어 두면 게임이
  잘 굴러갑니다.
- **정답 여러 개**: 쉼표로 나누면 무엇을 쳐도 정답입니다.
- **자동 인식의 한계**: 제목이 짧은 곡(`HIP`, `Oh!`, `200%`)은 가수 이름까지
  영상 제목에 있어야 인식됩니다. 인식이 안 되면 서버가 몇 번째 줄인지 알려
  주니 그 줄에 `| 정답`을 적으면 됩니다.
- **서버가 켜질 때 전부 검사합니다.** 잘못된 링크, 삭제된 영상, 인식 실패를
  줄 번호와 함께 출력하고 나머지는 그대로 진행합니다.

전체 형식은 [`../data/playlist.example.txt`](../data/playlist.example.txt)에
있습니다.

> **행사 전에 반드시 한 번 돌려 보세요.** 일부 영상은 업로더가 외부 재생을
> 막아 두었고, 그런 영상은 라운드가 통째로 날아갑니다. 미리 확인하면 화면에
> "이 영상은 외부 재생이 막혀 있습니다"라고 뜨므로 링크를 바꿀 수 있습니다.

#### 음원 파일 — 방장 화면에서 등록

복구된 곡 데이터에는 음원 URL이 들어 있지 않습니다. 등록하지 않으면 재생
가능한 곡이 0곡이 되어 방을 만들 수 없습니다.

| 입력 칸 | 내용 |
| --- | --- |
| 음원 URL | `http://` 또는 `https://` 주소만 허용됩니다. **라이선스가 확보된 음원만 사용하세요.** |
| 시작(초) | 클립을 재생하기 시작할 지점 |
| 끝(초) | 클립을 멈출 지점. 길이(끝−시작)는 **5초 이상 15초 이하**여야 합니다 |

- 검색창으로 목록을 좁힐 수 있습니다. 검색으로 걸러도 이미 입력한 값은
  사라지지 않습니다.
- 세 칸을 모두 채운 곡만 등록됩니다. 일부만 채운 곡은 조용히 제외되고, 방을
  만든 뒤 안내에 몇 곡이 제외되었는지 표시됩니다.
- 길이 조건을 어긴 곡은 안내 메시지로 알려 주고 그 곡만 제외됩니다. 나머지
  등록은 그대로 반영됩니다.
- 등록한 값은 **그 방에만 적용되며 서버에 저장되지 않습니다.** 매번 등록하는
  것이 번거로우면 곡 JSON 파일의 `mediaUrl` / `clipStart` / `clipEnd`를 직접
  채워 두세요([`SONG_DATA_GUIDE.md`](./SONG_DATA_GUIDE.md)).

### 2-3. 대기실과 시작

참가자가 들어오면 목록에 닉네임과 상태(`준비 완료` / `대기 중` / `접속 끊김`)가
표시됩니다. **게임 시작** 버튼은 방장에게만 보입니다. 참가자의 준비 상태와
관계없이 언제든 시작할 수 있습니다.

### 2-4. 라운드 진행 중

| 버튼 | 동작 |
| --- | --- |
| **일시정지** | 서버의 타이머를 멈춥니다. 멈춘 동안 제출한 정답은 처리되지 않습니다. |
| **재개** | 멈춘 만큼 제한 시간을 뒤로 밀어 재개합니다. 시간이 줄어들거나 늘어나지 않습니다. |
| **스킵** | 남은 시간을 즉시 0으로 만들고 정답을 공개합니다. 이미 누군가 맞혔다면 그 결과가 유지됩니다. |

방장의 연결이 끊기면 **서버가 자동으로 라운드를 일시정지**합니다. 아무도
진행할 수 없는 상태로 시간이 흐르는 것을 막기 위해서입니다.

## 3. 참가자 진행 순서

1. 첫 화면의 **방 참여**에 참여 코드와 닉네임을 넣고 **참여하기**를 누릅니다.
   참여 링크로 접속했다면 코드가 미리 채워져 있습니다.
2. 대기실에서 **준비** 버튼으로 상태를 바꿀 수 있습니다.
3. 라운드가 시작되면 정답 칸에 곡 제목을 입력하고 `Enter` 또는 **제출**을
   누릅니다.

닉네임이 겹치면 서버가 뒤에 `-2`, `-3`을 붙여 구분합니다. 이미 시작된 방에는
참여할 수 없습니다.

### 3-1. 정답 판정 결과

| 결과 | 표시 |
| --- | --- |
| 정답 | `정답입니다! +100점` — 라운드가 끝나고 정답이 공개됩니다 |
| 오답 | `"입력값" 은(는) 오답입니다. 다시 시도해 보세요.` |
| 이미 끝난 라운드 | `이미 다른 참가자가 맞혔습니다.` |

**오답은 나에게만 보입니다.** 다른 참가자에게 전달되지 않습니다. 남의 오답을
보고 정답을 좁혀 나가는 것을 막기 위한 규칙입니다. 같은 이유로, 라운드가 이미
끝난 뒤 제출한 답에 대해서는 **맞았는지 틀렸는지 알려 주지 않습니다.** 알려
주면 정답 공개 전에 정답이 새기 때문입니다.

한 라운드에 제출할 수 있는 횟수는 10회로 제한됩니다.

### 3-2. 정답 표기 규칙 (정규화)

띄어쓰기·대소문자·문장부호는 무시하고 비교합니다. 정답 칸 아래에 실제 판정에
쓰이는 값이 `판정 기준: …` 으로 표시되니 확인하며 입력할 수 있습니다.

| 입력한 값 | 결과 |
| --- | --- |
| `Dynamite` | 정답 |
| `dynamite` | 정답 (대소문자 무시) |
| `DYNAMITE!` | 정답 (느낌표 무시) |
| `다이나마이트` | 정답 (등록된 별칭인 경우) |
| `다이나 마이트` | 정답 (띄어쓰기 무시) |
| `Ｄｙｎａｍｉｔｅ` | 정답 (전각 문자 변환) |
| `butter` | 오답 |

한글 자모가 분리된 형태로 입력되거나(NFD) 다른 입력기에서 붙여넣어 겉모습만
같은 문자가 들어와도 같은 값으로 취급합니다. 구현과 시험은
[`shared/answerMatching.ts`](../shared/answerMatching.ts)와
[`shared/answerMatching.test.ts`](../shared/answerMatching.test.ts)에 있습니다.
**서버와 화면이 같은 파일을 가져다 쓰므로** 화면에 보이는 판정 기준과 서버의
판정이 어긋날 수 없습니다.

정답 판정은 **정규화 후 정확히 일치**하는지만 봅니다. 오타를 감안한 유사도
판정은 일부러 넣지 않았습니다. "누가 먼저 맞혔는가"를 다투는 게임에서 애매한
판정을 없애기 위한 결정입니다([`claude-analysis.md`](./claude-analysis.md) §8).

곡 제목에 괄호가 붙은 경우 괄호를 뺀 제목과 괄호 안 제목을 모두 정답으로
인정합니다 — `피노키오 (Danger)`는 `피노키오`와 `Danger` 둘 다 정답입니다.
다만 `Feat. …`, `Prod. …`처럼 참여 정보를 나타내는 괄호는 제외됩니다(피처링
가수 이름을 찍어서 맞히는 일을 막기 위해서입니다).

## 4. 점수와 순위

- **먼저 맞힌 한 사람만 1점**입니다. 그 순간 라운드가 끝나고 정답이 공개됩니다.
- 한 곡은 최대 **1분**입니다(재생 50초 + 답 쓸 시간 10초). 아무도 못 맞히면
  1분을 다 채우고 넘어갑니다.
- 곡이 많을수록 실력 차가 드러납니다. 한 곡을 얼마나 비싸게 이겼는지가 아니라
  **몇 곡을 이겼는지**로 순위가 갈립니다.
- 순위표는 **정답 공개 때만** 움직입니다. 라운드 도중에 순위가 흔들리면 그
  자체로 "누군가 맞혔다"는 신호가 되기 때문입니다.
- 점수가 같으면 **같은 순위**를 공유하고, 다음 순위는 그만큼 건너뜁니다
  (3점, 2점, 2점, 1점 → 1위, 2위, 2위, 4위).
- 라운드 화면에는 실시간 순위가, 게임이 끝나면 시상대와 전체 순위가 나옵니다.
- 내 행은 배경색으로 강조됩니다.

| 채팅 | **없음** | 정답 입력과 채팅을 섞으면 오답이 새기 때문에 넣지 않았습니다([`integration-plan.md`](./integration-plan.md) §1.3). |
| 힌트 | **없음** | 글자 수 힌트는 정답 정보를 흘리므로 제외했습니다. |
| 방 상태 영속화 | **미구현** | 서버를 재시작하면 진행 중이던 방은 사라집니다. |

## 6. 자주 겪는 문제

| 증상 | 원인과 조치 |
| --- | --- |
| 접속하니 Cloudflare **오류 1033**이 뜬다 | 그 주소의 터널이 이미 꺼졌습니다. 주소는 실행할 때마다 새로 생기고 창을 닫으면 사라집니다. 다시 실행해서 **새로 뜬 주소**를 쓰세요. |
| 노래가 참가자 폰에서 안 들린다 | 정상입니다. 노래는 방장 컴퓨터에서만 나오고 스피커로 다 같이 듣는 구조입니다([§1](#1-접속-요건)). |
| "이 영상은 외부 재생이 막혀 있습니다"가 뜬다 | 업로더가 임베드를 막아 둔 영상입니다. 플레이리스트에서 그 줄을 다른 링크로 바꾸세요. 행사 전에 미리 돌려 보면 걸러집니다. |
| 서버를 켤 때 "어느 곡인지 찾지 못했습니다"가 뜬다 | 영상 제목으로 곡을 특정하지 못했습니다. 메시지에 적힌 줄 번호를 찾아 `| 정답`을 직접 적으세요. |
| 방을 만들 수 없고 "재생 가능한 곡이 없습니다"가 뜬다 | 음원이 등록되지 않았습니다. [§2-2](#2-2-곡-준비) 참고. 흐름만 확인하려면 서버를 `--demo-clips`로 실행하세요. |
| 소리가 나지 않고 "브라우저가 자동 재생을 막았습니다"가 뜬다 | 브라우저 정책입니다. **음원 재생** 버튼을 한 번 누르면 이후 라운드부터 자동으로 재생됩니다. |
| "음원을 재생할 수 없습니다"가 뜬다 | URL이 잘못되었거나 브라우저가 재생할 수 없는 형식입니다. **라운드는 그대로 진행됩니다** — 시간은 서버가 관리하기 때문입니다. |
| 참여하려는데 "이미 시작된 방에는 참여할 수 없습니다"가 뜬다 | 대기실 단계에서만 참여할 수 있습니다. 방장이 새 방을 만들어야 합니다. |
| 정답을 냈는데 아무 반응이 없다 | 일시정지 중이거나 라운드 사이입니다. 타이머가 흐르고 있을 때만 판정합니다. |
| "서버와 연결되어 있지 않습니다" 토스트가 뜬다 | 연결이 끊겨 재접속 중입니다. 상단 상태 표시가 `연결됨`으로 돌아온 뒤 다시 시도하세요. |
| 새로고침했더니 처음 화면으로 돌아왔다 | 그 탭에서 아직 방에 참여하지 않았거나 다른 탭입니다. 세션은 탭 단위로 유지됩니다. |
| 방장 화면에서 시작 버튼이 보이지 않는다 | 그 탭에 방장 토큰이 없습니다. 방장 링크로 접속하세요. |
