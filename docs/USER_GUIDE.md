# 사용자 가이드 — Drop the Beat

온라인 노래 맞히기 게임 **Drop the Beat**의 화면과 조작 방법을 설명합니다.

> **이 문서를 읽기 전에 반드시 확인하세요.**
> 현재 배포된 것은 **작동하는 UI 프로토타입**입니다. 화면·타이머·정답 입력·순위 표시는
> 모두 **내 브라우저 안에서만** 동작합니다. 여러 사람이 같은 방에 들어와 함께 푸는
> 실시간 멀티플레이는 아직 구현되지 않았습니다. 어떤 기능이 실제로 동작하고 어떤
> 기능이 겉모습만 있는지는 [4. 지금 되는 것과 안 되는 것](#4-지금-되는-것과-안-되는-것)에
> 표로 정리해 두었습니다.

## 1. 접속 요건

| 항목 | 내용 |
| --- | --- |
| 기기 | **PC 전용**. 모바일·태블릿 레이아웃은 제공하지 않습니다. |
| 브라우저 | 최신 Chrome, Edge, Firefox 등 최신 데스크톱 브라우저 |
| 권장 해상도 | 가로 1280px 이상 (대기실·게임 화면이 3단 구성입니다) |
| 접속 주소 | <https://drop-the-beat-quiz.jyc686397.chatgpt.site> |
| 로그인 | 비공개 Sites 프로젝트로 배포되어 있어, 접근 권한이 있는 계정으로 로그인해야 페이지가 열립니다. 권한이 없으면 로그인 화면이나 오류 페이지가 표시됩니다. |
| 소리 | 현재 프로토타입은 **실제 음원을 재생하지 않습니다.** 화면의 음반·이퀄라이저는 애니메이션입니다. |

## 2. 화면 구성

상단 바는 모든 화면에 공통으로 나타납니다.

| 요소 | 하는 일 |
| --- | --- |
| 좌측 로고 **DROP THE BEAT** | 클릭하면 대기실로 이동합니다. |
| 가운데 **대기실 / 게임 / 결과** | 화면 미리보기 전환 버튼입니다. 실제 게임 진행과 무관하게 아무 화면으로나 건너뛸 수 있는 **데모용 내비게이션**입니다. |
| **서버 연결됨 28ms** | 고정된 표시값입니다. 실제 연결 상태나 지연 시간을 측정한 값이 아닙니다. |
| **ROOM CODE B7K2A** | 클릭하면 방 코드가 클립보드에 복사되고 안내 토스트가 뜹니다. 코드 자체는 고정값입니다. |
| 우측 원형 아이콘 | 방장 표시입니다. |

화면은 대기실 → 게임 → 결과 세 단계로 이어집니다.

## 3. 방장(호스트) 진행 순서

### 3-1. 대기실에서 준비

1. 참가자 목록에서 인원과 준비 상태를 확인합니다. 카드에 `READY`가 뜬 사람이 준비 완료,
   `WAITING`이면 아직 준비 전입니다. 방장 카드에는 `HOST`가 표시됩니다.
2. 우측 **게임 설정** 카드에서 값을 조정합니다.

| 설정 | 조작 | 동작 여부 |
| --- | --- | --- |
| 출제 곡 수 | 슬라이더, 10~40곡을 5곡 단위로 선택 | **동작합니다.** 이후 라운드 수와 결과 화면 정답률 계산에 실제로 반영됩니다. |
| 제한 시간 | `12초` 표시 | 고정 표시입니다. 아직 바꿀 수 없습니다. |
| 힌트 공개 | `종료 5초 전` 표시 | 고정 표시입니다. |
| 정답 공개 | 토글 스위치 | 항상 켜진 모습으로 고정되어 있습니다. |

3. **SCX에서 찾은 곡** 카드에서 등록된 곡 목록을 확인합니다. `+ 미디어 URL 연결하기`를
   누르면 "다음 구현 단계입니다"라는 안내만 표시됩니다. 음원 등록 화면은 아직 없습니다.
4. **게임 시작**을 누르면 게임 화면으로 넘어갑니다.

### 3-2. 라운드 진행 중

화면 가운데 아래 **HOST CONTROL** 영역에 방장 전용 버튼이 있습니다.

| 버튼 | 동작 |
| --- | --- |
| `Ⅱ 일시정지` / `▶ 계속` | 타이머를 멈추고 다시 진행합니다. 멈춘 동안에는 정답을 입력할 수 없습니다. |
| `현재 곡 스킵` | 남은 시간을 0으로 만들고 정답을 공개합니다. 이 라운드는 정답자 없이 끝납니다. |

정답이 공개되면 가운데 패널에 정답 카드가 뜨고, **다음 라운드** 버튼이 나타납니다.
마지막 곡이면 버튼이 **최종 결과 보기**로 바뀝니다.

### 3-3. 결과 확인

- 상단에 1~3위 시상대가 표시됩니다.
- 아래 **FINAL RANKING** 표에 전체 참가자의 순위, 맞힌 곡 수, 정답률, 최종 점수가 나옵니다.
  본인 행은 `YOU` 배지와 함께 강조됩니다.
- **대기실로 돌아가기** 또는 **한 판 더**로 다시 시작할 수 있습니다.

## 4. 참가자 진행 순서

### 4-1. 준비

대기실에서 참가자 카드의 준비 상태를 확인합니다. 현재 프로토타입에는 **참가자가 직접
누르는 준비 버튼이 없습니다.** 표시된 참가자 20명과 준비 상태는 화면 구성을 보여주기
위한 예시 데이터입니다.

### 4-2. 정답 입력

게임 화면 오른쪽 아래 **정답 입력** 칸에 곡 제목을 적고 `Enter` 또는 `ENTER` 버튼을
누릅니다.

- 정답이면 정답 카드가 열리고 점수가 올라갑니다.
- 정답이 아니면 입력한 내용이 아래 채팅 목록에 그대로 올라갑니다.
- 일시정지 중이거나 정답이 이미 공개된 뒤에는 입력 칸이 비활성화됩니다.

> 프로토타입에서는 **첫 번째 곡(Dynamite)의 정답만** 판정합니다. 라운드 번호와 관계없이
> `Dynamite` 또는 `다이나마이트`를 입력해야 정답 처리됩니다.

### 4-3. 정답 표기 규칙 (정규화)

띄어쓰기·대소문자·문장부호는 무시하고 비교합니다. 아래는 모두 같은 답으로 인정됩니다.

| 입력한 값 | 결과 |
| --- | --- |
| `Dynamite` | 정답 |
| `dynamite` | 정답 (대소문자 무시) |
| `DYNAMITE!` | 정답 (느낌표 무시) |
| `다이나마이트` | 정답 |
| `다이나 마이트` | 정답 (띄어쓰기 무시) |
| `Ｄｙｎａｍｉｔｅ` | 정답 (전각 문자 변환) |
| `butter` | 오답 |

한글 자모가 분리된 형태로 입력되거나(NFD), 다른 입력기에서 붙여넣어 겉모습만 같은
문자가 들어와도 같은 값으로 취급합니다. 이 규칙의 구현과 시험은
[`shared/answerMatching.ts`](../shared/answerMatching.ts)와
[`shared/answerMatching.test.ts`](../shared/answerMatching.test.ts)에 있습니다.

정답 판정은 **정규화 후 정확히 일치**하는지만 봅니다. 오타를 감안한 유사도 판정은
일부러 넣지 않았습니다. "누가 먼저 맞혔는가"를 다투는 게임에서 애매한 판정을
없애기 위한 결정입니다. 자세한 근거는
[`claude-analysis.md`](./claude-analysis.md) §8에 있습니다.

곡 제목에 괄호가 붙은 경우(`피노키오 (Danger)` 등) 괄호를 뺀 제목과 괄호 안 제목을
모두 정답으로 인정하는 규칙이 [`shared/songCatalog.ts`](../shared/songCatalog.ts)에
준비되어 있습니다. 다만 이 규칙은 **아직 화면에 연결되지 않았습니다.**

### 4-4. 순위 확인

게임 화면 왼쪽 **LIVE RANKING** 패널에 상위 5명과 내 순위가 표시됩니다.
전체 순위는 게임이 끝난 뒤 결과 화면에서 확인합니다.

## 5. 지금 되는 것과 안 되는 것

| 기능 | 상태 | 설명 |
| --- | --- | --- |
| 대기실 / 게임 / 결과 화면 이동 | **동작** | 상단 데모 내비게이션과 게임 진행 버튼 모두 동작합니다. |
| 출제 곡 수 설정 | **동작** | 10~40곡, 5곡 단위. |
| 0.1초 단위 라운드 타이머 | **동작** | 내 브라우저에서 계산합니다. |
| 일시정지 / 계속 / 스킵 | **동작** | 내 화면에만 적용됩니다. |
| 정답 입력·정규화 판정 | **부분 동작** | 첫 번째 곡(Dynamite)에 대해서만 판정합니다. |
| 순위표·시상대·최종 순위 | **부분 동작** | 참가자 20명과 점수는 미리 넣어 둔 예시 값입니다. |
| 복구된 곡 목록 표시 | **부분 동작** | 화면에는 6곡만 예시로 보여 줍니다. 복구 원본은 171곡입니다. |
| 채팅 | **부분 동작** | 예시 메시지가 미리 들어 있고, 내가 입력한 오답이 여기에 추가됩니다. 다른 사람에게 전달되지는 않습니다. |
| **여러 명이 함께 하는 실시간 플레이** | **미구현** | WebSocket 서버가 아직 없습니다. |
| **방 만들기 / 참여 / 닉네임 입력** | **미구현** | 방 코드 `B7K2A`는 고정 표시값입니다. |
| **방장 권한 확인** | **미구현** | 일시정지·스킵 버튼에 권한 검사가 없습니다. |
| **새로고침 후 이어하기** | **미구현** | 새로고침하면 처음 상태로 돌아갑니다. |
| **실제 음원 재생** | **미구현** | 재생 화면은 애니메이션이며, 등록된 음원 URL이 없습니다. |
| **서버 기준 선착순 판정** | **미구현** | 현재 판정은 내 브라우저에서 이루어집니다. |

실시간 멀티플레이를 어떤 설계로 구현할지는
[`claude-analysis.md`](./claude-analysis.md)와
[`realtime-protocol.md`](./realtime-protocol.md)에 정의되어 있고,
프로토타입을 그 설계로 옮기는 순서는
[`integration-plan.md`](./integration-plan.md)에 정리되어 있습니다.

## 6. 자주 겪는 문제

| 증상 | 원인과 조치 |
| --- | --- |
| 페이지가 열리지 않고 로그인 화면이 뜬다 | 비공개 배포입니다. 접근 권한이 있는 계정으로 로그인하세요. |
| 화면이 겹치거나 잘려 보인다 | 창 너비를 1280px 이상으로 넓히세요. PC 전용 레이아웃입니다. |
| 소리가 나지 않는다 | 정상입니다. 아직 음원이 연결되어 있지 않습니다. |
| 정답을 입력해도 계속 오답 처리된다 | 프로토타입은 `Dynamite` / `다이나마이트`만 정답으로 인정합니다. |
| 타이머가 0이 되어도 다음 곡으로 넘어가지 않는다 | 정답 공개 후 **다음 라운드** 버튼을 눌러야 넘어갑니다. 자동 진행은 서버 구현 단계의 기능입니다. |
| 방 코드를 복사해 다른 사람에게 보냈는데 같은 방에 들어오지 못한다 | 방 참여 기능이 아직 없습니다. 코드는 화면 예시입니다. |
| 새로고침했더니 점수가 사라졌다 | 모든 상태가 브라우저 메모리에만 있습니다. 서버 구현 전까지는 정상 동작입니다. |
