# SsafyDay React 클라이언트

권위 게임 서버(`../server/`)에 연결되는 React 화면입니다. 브라우저는 화면만
그리고, 정답 판정·선착순·타이머·점수·힌트는 서버가 결정합니다.

현재 포함된 화면과 상호작용:

- 최대 20명 대기실과 준비 상태
- 방 생성, 챕터별 문제 수 설정, 참여 코드 입장
- 노래 → 속담 → 사자성어의 고정 진행 순서
- `문제/곡목록.txt`의 유튜브 하이라이트를 방장 컴퓨터에서만 재생
- 서버 기준 0.1초 단위 타이머, 일시정지, 문제·챕터 스킵, 조기 종료
- 속담·사자성어의 남은 30초 힌트와 실시간 득점자 피드
- 본인에게만 보이는 정답·오답 판정
- 게임 중 실시간 TOP 5와 내 순위
- 1~3위 시상대와 전체 최종 순위
- 새로고침 후 세션 복구

```powershell
npm install
npm run dev
npm test
```

로컬에서 실제 게임을 하려면 UI와 게임 서버를 함께 실행해야 합니다. 자세한
명령은 [`../docs/DEVELOPMENT.md`](../docs/DEVELOPMENT.md) §2에 있습니다.

Sites에 저장된 현재 배포 버전은 이 코드보다 오래된 초기 프로토타입입니다.
최신 UI를 배포하려면 별도 공개 게임 서버를 먼저 준비하고 빌드 시
`VITE_GAME_SERVER`를 지정해야 합니다.
