# SsafyDay

PC 전용 실시간 온라인 노래 맞히기 게임의 작동형 프런트엔드 프로토타입입니다.

현재 포함된 화면과 상호작용:

- 최대 20명 대기실과 준비 상태
- 방장 게임 설정 및 시작
- 0.1초 단위 라운드 타이머, 일시정지, 스킵
- 문자열 정규화 기반 정답 입력 데모 (`Dynamite`, `다이나마이트`)
- 게임 중 실시간 TOP 5와 내 순위
- 1~3위 시상대와 전체 1~20위 최종 순위
- SCX에서 복구한 대표 곡 정보

```powershell
npm install
npm run dev
npm test
```

이 버전은 UI/게임 루프 프로토타입입니다. 실제 다중 사용자 운영에는 저장소 루트의 `docs/realtime-protocol.md`에 정의된 권위 서버와 WebSocket 구현, 라이선스가 확보된 미디어 URL 등록이 추가되어야 합니다.
